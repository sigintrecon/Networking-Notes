## About This Repository

This is my personal Computer Networking learning portfolio — built from scratch, structured for long-term growth, and designed as a revision resource at every stage of my journey.

Learning direction:

- Computer Networking and Network Administration
- Cybersecurity and Ethical Hacking
- Red Team Operations and Network Reconnaissance
- eJPT Certification Preparation

Everything starts from fundamentals. Each module explains the **why before the how**.

## Learning Methodology

1. Understand the concept before memorizing commands
2. Explain the why before the how
3. Use realistic IP addresses and network scenarios
4. Verify understanding through self-reflection questions
5. Build practical lab notes alongside theory
