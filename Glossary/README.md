# Glossary

Quick reference for networking and security terms.

| Term | Definition |
|------|-----------|
| ARP | Address Resolution Protocol — resolves IP to MAC address |
| Broadcast | A packet sent to all devices on a network segment |
| CIDR | Classless Inter-Domain Routing — slash notation for subnet masks (/24) |
| Default gateway | The router IP that handles traffic leaving the local network |
| DHCP | Dynamic Host Configuration Protocol — auto-assigns IP configuration |
| DNS | Domain Name System — translates domain names to IP addresses |
| Encapsulation | Adding headers at each layer as data moves down the OSI stack |
| Ethernet | Standard Layer 2 wired networking technology |
| FCS | Frame Check Sequence — error detection field in Ethernet frames |
| Frame | Layer 2 PDU (Ethernet frame) |
| Hub | Layer 1 device that sends traffic to all ports — obsolete |
| ICMP | Internet Control Message Protocol — diagnostics (ping, traceroute) |
| IP | Internet Protocol — Layer 3 addressing |
| LAN | Local Area Network |
| LPM | Longest Prefix Match — most specific route in a routing table wins |
| MAC | Media Access Control address — hardware address of a NIC |
| NAT | Network Address Translation — maps private IPs to a public IP |
| NIC | Network Interface Card |
| Octet | 8-bit group in an IP address |
| OSI | Open Systems Interconnection — 7-layer networking model |
| Packet | Layer 3 PDU (IP packet) |
| PAT | Port Address Translation — NAT using port numbers |
| PDU | Protocol Data Unit — name for data at each OSI layer |
| Ping | ICMP-based connectivity test |
| Port | Logical endpoint for a service (TCP/UDP port number) |
| Router | Layer 3 device — routes packets between networks |
| Routing table | A list of network destinations and next hops |
| Segment | Layer 4 PDU (TCP segment) |
| SMB | Server Message Block — Windows file and printer sharing |
| SSH | Secure Shell — encrypted remote access |
| Subnet | A smaller network carved out of a larger IP address space |
| Subnet mask | Defines which part of an IP address is network vs host |
| Switch | Layer 2 device — forwards frames based on MAC addresses |
| TCP | Transmission Control Protocol — reliable, connection-oriented |
| TLS | Transport Layer Security — encrypts data in transit |
| TTL | Time To Live — hop count field in IP packets |
| UDP | User Datagram Protocol — fast, connectionless |
| Unicast | A packet sent to one specific device |
| VLAN | Virtual LAN — logical network segmentation on a switch |
| VLSM | Variable Length Subnet Masking — different prefix lengths within one network |
| WAN | Wide Area Network |
