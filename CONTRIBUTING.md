# Contributing Guidelines

This repository is primarily a personal learning portfolio.

If you have spotted a technical error, have a suggestion, or want to contribute a correction, feel free to open an issue or submit a pull request.

## Guidelines

- Keep language beginner-friendly
- Ensure technical accuracy — verify port numbers, protocol behavior, and command syntax
- Follow the existing module structure and documentation template
- Use Mermaid diagrams where they genuinely improve understanding
- Do not add content that promotes unauthorized access to systems or networks
- All lab exercises must be safe and legal

## Pull Request Format

- Clear title describing what was changed
- Brief description of the change and why
- Reference the relevant module number
